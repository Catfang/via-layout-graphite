Graphite keyboard layout config for Via

This is my personal keyboard layout for my Iris CE (and now LM) keyboards.

There are a number of multipurpose keys. The 'T' and the 'A' keys (under the home row middle fingers) act as 'SHIFT' if held down. The two thumb keys are similiar in that they are 'SPACE' if tapped and are a layer shift if held. Common macros are on the lower left row when layer-switched.
